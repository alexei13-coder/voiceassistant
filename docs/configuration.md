# Настройки и файлы данных

## Где лежат данные

| ОС | Папка данных |
|---|---|
| Windows | `%APPDATA%\Swyvorn\` |
| Linux (разработка) | `$XDG_CONFIG_HOME/swyvorn/` или `~/.config/swyvorn/` |
| macOS (разработка) | `~/Library/Application Support/Swyvorn/` |

Переопределить: переменная `SWYVORN_DATA_DIR` или флаг `--data-dir`.

Внутри папки данных:

```
settings.toml        настройки (создаётся с комментариями при первом запуске)
.env                 секреты: ANTHROPIC_API_KEY=...
logs/core.log        лог ядра (ротация: 1 МБ × 5 файлов), секреты вырезаны
```

Позже (этап 2+): `memory.json`, `contacts.toml`, `logs/audit.jsonl`.

## Порядок загрузки `.env`

1. Переменные окружения процесса (имеют приоритет).
2. `<папка данных>/.env`.
3. Только в режиме `--dev`: `.env` в корне репозитория.

Ключ API хранится в памяти как `SecretStr` и никогда не попадает в лог, в UI и в сообщения протокола.

## `settings.toml`

```toml
[assistant]
name = "SWYVORN"              # имя ассистента
address_form = "сэр"          # как обращаться к пользователю; спросим при первом запуске (этап 2)

[llm]
model = "claude-opus-5-5"
effort = "low"                # low | medium | high

[hotkeys]
activate = "Ctrl+Alt+J"       # нажатие — вызов, удержание — говорить, пока держите
stop = "Ctrl+Alt+Escape"      # остановить всё
stop_fallback = "Ctrl+Alt+Backspace"  # если основное сочетание занято
mute = "Ctrl+Alt+M"           # не слушать / слушать
repeat = "Ctrl+Alt+R"         # повторить последний ответ
screen = "Ctrl+Alt+S"         # посмотреть на экран

[ui]
reduced_motion = false        # меньше анимаций для слабых ПК

[demo]
enabled = true                # этап 1: демонстрационный сценарий вместо «мозга»

[logging]
level = "INFO"                # DEBUG | INFO | WARNING | ERROR
```

Неизвестные ключи игнорируются с предупреждением в логе. Неверные значения → значение по умолчанию и предупреждение (ядро не падает из-за опечатки в настройках).

## Аргументы командной строки ядра

```
python -m swyvorn [--dev] [--port N] [--demo | --no-demo] [--no-stdin]
                 [--data-dir PATH] [--log-level LEVEL]
```

| Флаг | Значение |
|---|---|
| `--dev` | режим разработки: разрешены Origin `http://localhost:1420`, читается `.env` из корня репозитория, без `SWYVORN_IPC_TOKEN` токен генерируется и печатается в stderr |
| `--port N` | порт WebSocket; `0` — случайный (по умолчанию: `0` без `--dev`, `8765` с `--dev`) |
| `--demo` / `--no-demo` | переопределить `[demo] enabled` |
| `--no-stdin` | не слушать управляющий канал stdin (запуск без оболочки) |
| `--data-dir PATH` | папка данных |
| `--log-level LEVEL` | уровень логирования |

Коды выхода: `0` — нормальное завершение, `2` — ошибка аргументов, `3` — запущено от имени администратора (запрещено), `4` — не удалось открыть порт, `1` — прочие ошибки.
